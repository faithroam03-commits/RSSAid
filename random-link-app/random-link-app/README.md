# Random Link App

登録したWebページからタイトル・サムネイルを取得し、トップページやジャンル別ページでランダム表示する個人向けWebアプリです。

## 第1版でできること

- URL登録
- `og:title` / `twitter:title` / `<title>` からタイトル自動取得
- `og:image` / `twitter:image` からサムネイル自動取得
- 登録直後はジャンル「新規登録」
- 全URLからランダム表示
- ジャンル別ランダム表示
- 「別のページ」ボタンで再抽選
- 管理画面でタイトル、URL、サムネイル、ジャンル、有効/無効を編集
- 元ページから画像候補を最大30件取得し、サムネイルとして選択
- URL削除
- SQLiteによるローカル保存

## セットアップ

Node.js の現行LTS版を用意してください。

```bash
npm install
npm run dev
```

ブラウザで以下を開きます。

```text
http://localhost:3000
```

SQLiteデータベースは初回起動時に `data/app.db` として自動作成されます。

## 画面

- `/` ランダム表示
- `/register` URL登録
- `/genres` ジャンル一覧
- `/genre/ジャンル名` ジャンル別ランダム表示
- `/admin` URLメンテナンス
- `/admin/ID` URL編集・画像候補選択

## セキュリティ

URLをサーバー側から取得するため、SSRF対策として以下を実装しています。

- HTTP / HTTPS 以外を拒否
- localhostを拒否
- プライベートIPv4 / IPv6を拒否
- DNS解決後のプライベートアドレスを拒否
- リダイレクト先も再検証
- 8秒タイムアウト
- HTML取得サイズを約2MBに制限

### 重要

この第1版には管理画面のログイン認証がありません。
**インターネットへ一般公開する前に、必ず認証を追加してください。**

また、Webサイトによってはbot対策、JavaScriptレンダリング、画像のホットリンク防止などによりタイトル・画像を取得できない場合があります。
